# ⏰ Desktop Notifier (Python)

A simple Python desktop notification application that sends reminders using the `plyer` library.

---

## 🚀 Features
- Sends desktop notifications
- Lightweight and fast
- Easy to customize messages
- Runs in background

---

## 🛠️ Technologies Used
- Python 3
- plyer library

---

## 📦 Installation

### 1. Install Python
Make sure Python is installed on your system.

### 2. Install required library
```bash
pip install plyer
